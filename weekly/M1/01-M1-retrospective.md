## 三、实弹根因志（AI 域两大方法论支柱 + DevOps 坑位账）

1. **信号量双重获取泄漏**：Mock 掉 LlmClient 后守卫代码不在测试路径——并发守卫类必须实弹验证（方法论入 05 §④）；
2. **裸换行符**：qwen2.5:7b JSON 内裸 \n 违反 RFC 8259——宽松解析模式 + 真实模型输出回归；
3. **数字锚反噬**：负向约束里的数字区间成为锚（严禁65~80→样本全打68）——原创观察入 05 §四 D-29；
4. **prompt 迭代五轮证伪链**：V8 最优解 + "继续迭代是随机游走"判断——假设→实验→证伪→止损科学闭环；
5. **CI 六周悬置期复盘**：暂停原因（网络+决策双悬）→ 恢复后 socks5 代理链路 + 三跳推送 + 三轮修复至五绿——教训：CI 门禁从项目第一天就应在线，本地证据链替代口径是减分项且答辩必被问；
6. DevOps 坑位六连（Jackson/ECJ/agent/ollama窗口/mvn clean/nginx DNS）入 06 附录防复发清单。
