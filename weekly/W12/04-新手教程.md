# SWE-AIES 新手教程（完整演示 Walkthrough）

> 环境实测背书：7 容器 healthy、nginx:8082→200（2026-11-16 预检）；教程内所有"预期结果"均来自实弹记录。
> 访问入口：**http://localhost:8082**（前端+API 同端口，nginx 统一入口）。

## 第零步：环境启动（第一次使用）

```powershell
cd d:\MyChook\新建文件夹\11-\11-
docker compose -f compose-dev.yml up -d     # 拉起全套（首次含镜像拉取）
docker ps                                    # 等待全部 healthy（约 30~60s）
```

预检清单：`aies-dev-app-1`（SpringBoot）、`mysql`、`redis`、`rabbitmq`、`minio`、`ollama`、`nginx` 全部 healthy。应用启动含 Flyway 自动迁移（当前 schema v14），日志看到 `Started AiesApplication` 即就绪。

## 第一步：登录（第一幕）

1. 浏览器打开 **http://localhost:8082** → 登录页
2. 输入用户名（三角色：`admin` / `teacher` / `student`，密码见 COMPOSE-DEV.md 环境说明——演示密码口径）
3. **图形验证码**：点击图片刷新，输入图中字母数字（后端 Redis 校验，错码会提示）
4. 预期：登录成功跳转主界面，顶栏显示角色（教师见任务管理/复核菜单，学生见提交/我的报告）

> 没有账号？走第〇附加步注册（见下）。

## 第〇附加步：注册与找回密码（分支演示）

1. 登录页点"注册"→ 填手机号/密码 → 获取验证码 → **dev 模拟通道**：验证码在响应中回显（演示话术："传输层模拟，配置 SMTP_* 即真发"）
2. 输入回显码（实测样例 668796）→ 注册成功，用新账号登录
3. 忘记密码：登录页"找回"→ 同样回显码流程 → 重置后新密码登录（实测闭环）

## 第二幕：教师建任务

1. 教师登录 → 任务管理 → 新建任务（标题/要求/指标集：功能正确性40/代码质量35/文档规范25）
2. 预期：任务列表出现新任务，状态可发布

## 第三幕：学生提交作业

1. 学生登录 → 任务列表 → 选任务 → 上传 **.docx** 文件（≤20MB）
2. 预期：提交成功，解析状态 `QUEUED` → 几秒后变 `SUCCESS`（RabbitMQ 异步解析链，parsed 文本入 MinIO）

## 第四幕：AI 自动评分（核心亮点）

1. 解析 SUCCESS 后系统**自动**投递评分消息（无需手动触发）→ Ollama GPU（qwen2.5:7b）推理
2. 提交详情页刷新：状态 `AI_DONE`，显示总分+三指标分+AI 评语；`FAILED` 时显示 40003 错误码（可重评）
3. 实测节奏：单篇约 8~10s；并发 2 槽；超时自动重试兜底（黄金集 20/20 exit 0）

## 第五幕：报告与复核（收尾亮点）

1. 学生：我的报告 → 报告页（UC-21）看到总分/进度条/逐指标/AI 评语/版本号
2. 教师：复核工作台 → 选学生作业 → 调整分数+复核理由（≥10字）→ 落库生成新版本（history 版本+1，实测 58→62 v2）
3. **报表页（UC-25，M2 主打）**：教师侧 `GET /api/reports/overview` 返回四图（任务统计/均分分布/指标雷达/分差分布）；演示亮点动作——**复核改分后立刻刷新报表，数据即时变更**（AFTER_COMMIT 缓存失效，无 10min 陈旧窗口，实测三步实拍）
4. 学生侧个人报表：`GET /api/reports/overview/me`（40400 同形保护：查他人 404）

## 黄金集回放（答辩演示加分项）

```powershell
docker cp backend\target\aies-server-1.0.0.jar aies-dev-app-1:/tmp/a.jar
docker exec aies-dev-app-1 java -jar /tmp/a.jar --eval.replay=true --spring.main.web-application-type=none
```

预期：20 个标准样本批量送评，逐样本打印 AI 分 vs 教师分 vs 阈值判定，失败自动重试，末尾汇总一致率（V8 模板下 65%@20样本——边界实证叙事见复盘报告）。

## 故障预案（演示场应急）

| 症状 | 处置 |
|------|------|
| 页面打不开 | `docker restart aies-dev-app-1`（12.9s 恢复实测）；确认 8082 非 8081（D-32 改道） |
| AI 评分卡住 | ollama 重启后需 `docker exec aies-dev-ollama-1 ollama ps` 确认模型 loaded（重载 60s 窗口）再送评 |
| 验证码总错 | 点图片刷新（Redis 时效 5min） |
| 登录被踢/token 过期 | 重新登录即可（JWT 2h） |
| 页面空白/数据旧 | 清浏览器缓存（localStorage 残留 token 会跳过登录守卫） |

## 演示动线建议（10 分钟版）

登录(1min) → 教师建任务(1min) → 学生上传+解析(2min) → AI 评分等待+报告(2min) → 教师复核改分(1min) → 报表页刷新看即时变更(2min) → 注册/找回分支话术(1min)。
